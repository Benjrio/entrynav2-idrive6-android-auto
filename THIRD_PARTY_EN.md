# Third-party components

[Русский](THIRD_PARTY_RU.md) | **English**

`runtime/aa/lib` contains dynamic FFmpeg 7.1.1 and OpenSSL 1.0.1 libraries.
`third-party/` retains the source archives, Ubuntu patch archive, FFmpeg source
patch, and license texts. These files accompany the libraries in use and must
be retained when distributing them.

The AA sources retain attribution to aasdk (f1x.studio, GPL-3.0-or-later) in
`src/aa-protocol.h` and `src/aa-phone-version.h`.
The project's own source code is licensed under GPL-3.0-or-later (LICENSE).
This does not replace the licenses of third-party code or local dependencies.

Local SDKs, original head unit libraries, scene binaries, the TLS identity, and
the icon are provided separately as described in [PRIVATE_INPUTS_EN.md](PRIVATE_INPUTS_EN.md).
